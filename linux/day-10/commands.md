# Networking Basics

## Connectivity & Configuration

- `ping <host>` : Test connectivity to a host using ICMP echo requests.
- `ip a` : Show IP addresses assigned to network interfaces.
- `ip link` : Show network interfaces and their current state.
- `ifconfig` : Display or configure network interfaces (legacy command).
- `hostname` : Display the system's hostname.
- `hostname -I` : Show the machine's IP address(es).
- `ip route` : Display the system's routing table.
- `ip neigh` : Show the ARP/neighbor table.
- `ss -tuln` : Show listening TCP and UDP ports.
- `curl <url>` : Transfer data from or to a server using a URL.
- `wget <url>` : Download files from the web.
- `nslookup <domain>` : Query DNS information for a domain.
- `dig <domain>` : Perform detailed DNS queries.
- `traceroute <host>` : Show the network path taken to reach a host.
- `hostname -f` : Display the fully qualified domain name (FQDN).
