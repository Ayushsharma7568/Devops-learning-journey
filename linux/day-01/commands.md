\# Terminal Basics \& Navigation



\## Terminal Basics



| Command | Description |

|---------|-------------|

| `pwd` | Print the current working directory |

| `whoami` | Display the current logged-in user |

| `clear` | Clear the terminal screen |

| `date` | Display the current date and time |

| `cal` | Show the calendar |

| `echo` | Print text or variable values to the terminal |

| `history` | Display previously executed commands |

| `man <command>` | Display the manual page for a command |

| `<command> --help` | Show a command's help and available options |

| `exit` | Close the current terminal session |



\---



\## Navigation



| Command | Description |

|---------|-------------|

| `ls` | List files and directories |

| `ls -l` | Display files in long listing format (permissions, owner, size, modified date, etc.) |

| `ls -a` | Show all files, including hidden files (starting with `.`) |

| `ls -lh` | Display files in long listing format with human-readable sizes (KB, MB, GB) |

| `cd <directory\_name>` | Change to the specified directory |

| `cd ..` | Move up one level to the parent directory |

| `cd` or `cd \~` | Return to the current user's home directory |

| `cd -` | Switch back to the previous working directory |

| `tree` | Display the directory structure in a tree-like format |
